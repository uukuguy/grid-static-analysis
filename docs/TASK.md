# Grid-Static-Analysis TASK

## 一、任务背景

随着新能源大规模接入、跨区输电规模扩大和电网运行方式日益复杂，大规模输电网潮流分布及安全风险呈现强耦合、多场景和快速变化特征。大语言模型与智能体技术可通过自然语言理解调度分析要求，自动拆解任务并调用潮流计算、故障校核和结果检索工具。为检验相关系统在大电网专业分析中的实际能力，本测评聚焦大规模输电网静态安全分析，重点考察受测系统能否准确理解自然语言指令，正确调用专业仿真工具，完成关键线路筛选、交流潮流计算、N-1校核、风险排序及证据化结论生成。

## 二、测评任务

任务:大电网静态安全分析智能体交互评测
采用开源pandapower(版本3.4.0)作为电力系统仿真软件调度交互工具，企业需要基于自身智能体，完成连续自然语言交互下的具体电力系统仿真计算、数据采集等任务的理解、任务规划、执行等任务。本次测试主要考察企业人工智能与专业仿真工具融合能力，对比企业智能体识别分析对象、运行方式、计算方法、筛选范围和输出要求的能力。
本任务不设数据集上传环节。评测方基于开源仿真工具pandapower及自行收集的数据自行构建测试环境，完成测评任务。

## 三、测试任务示例

其中，question可设示例:

IEEE-39节点系统中线路11连接哪两个母线?
母线电压正常运行范围是多少?
N-1静态安全校核需要检查哪些越限类型?
潮流计算工具（pandapower runpp）需要输入哪些参数?
对IEEE-39节点系统运行交流潮流，并输出有功网损;
筛选负载率最高的5条线路;
对线路17开展N-1校核;
对关键线路逐一进行故障分析并排序;
根据仿真结果输出母线低电压、线路过载等风险及其证据。

## 四、输出数据格式

question_id string 问题唯一编号

answer_output string 输出答案
